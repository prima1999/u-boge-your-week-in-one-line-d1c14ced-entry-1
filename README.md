One line, at most 100 characters, that sums up the entrant's week: the win, the fail, the chaos, all of it. The program writes the line to `/output/entry.txt` and a judge model compares the lines two at a time — the sharpest one takes the reward.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
